# My taste profile

Edit freely (Persian or English). Claude reads this before every prompt.

## Default density
minimal
<!-- options: ultra-minimal, minimal, balanced, maximal, or "random" -->

## Always avoid
- Generic SaaS layout: centered hero + two buttons + three icon cards
- Purple/blue gradients, glassmorphism, emoji, stock 3D blobs
- Busy pages: more than one attention-grabbing element per screen
- Invented numbers, prices or testimonials
- Marketing words: seamless, elevate, unlock, empower, revolutionize

## I tend to like (light touch, not a style to repeat)
- Strong typographic hierarchy
- Precise details: exact spacing, considered hover and focus states

## Technical defaults
- Single self-contained HTML file, plain CSS + vanilla JS, no frameworks
- Works at phone width (390px) with no horizontal scroll
- Respects prefers-reduced-motion; text contrast at least 4.5:1
